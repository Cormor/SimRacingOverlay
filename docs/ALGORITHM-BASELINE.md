# 算法基线：adaptive-steering-v1-20261024

当前存档标记为 **adaptive-steering-v1-20261024**。配套 JSON 记录源码身份、存档路径与验证数据。存档是用户要求保留的算法维护材料；原始操控录制继续保留，不纳入日志清理。

## 保持的行为

- 默认运动学观察器固定为今晚 DeepSeek 修改前的 v15 实现，运行代码在 `legacy-chassis-response.js`。与修改前存档逐行对照一致，仅浏览器导出名称独立。
- iRacing 适配器显式提供版本化契约 `capabilities.kinematicsProfile=adaptive-steering-v1`，才使用 `chassis-response.js` 的自适应观察器。其他已有输入保留旧模型。算法仍检查实际字段与能力，不依靠游戏名称推断数据。
- 原生逐轮侧滑、滑移率、载荷和轮胎力优先；模型观察不覆写原生字段。悬架全伸展依据实际 `shockDeflectionM/shockVelocityMs`，不伪造接触传感器。
- 显示侧偏角复用原前后轴侧滑条；没有原生侧滑时才使用有明确来源的估计。

## 本次两个直接优化

1. 在线几何识别将 `exp(-16/2000)` 的错误更新权重修正为 `1-exp(-dt/2000)`。原式每帧几乎用新值替换旧值；修正后为两秒时间常数，10 / 20 / 40 ms 输入间隔的结果一致。已有准确几何时跳过冗余识别。
2. 无几何路径原本将 `steerNow` 固定为零，导致参考负荷学习条件永远失败。现在使用已存在的运动学尺度计算转向需求，恢复该路径的观测学习。参考变化限速和前后裕度恢复限制保留。
