# SimRacingOverlay v1.0.1

## 更新内容

- 增加 F1 25 的 2025 格式 UDP 接入，读取四轮滑移率、侧滑角、轮胎力和载荷。
- 有效 UDP 优先，其次是有效共享内存，原生来源不可用时才采用 SimHub 备用数据。较慢的 HTTP 读数不再否决原生来源，也不补入原生动态快照。
- 可选字段分别处理，缺少一项不再关闭整套轮胎与转向趋势显示。
- 按钮编号仅在按下时显示。
- 更新遥测接入说明、适配规则和针对性检查。

## 下载与使用

下载 **SimRacingOverlay-1.0.1-Windows-x64.zip**，完整解压后运行 **Install.cmd**。更新前关闭 overlay 和启动观察器；需要更新 SimHub 插件时也应先正常关闭 SimHub。已有设置、输入校准和布局会保留。

F1 25 请在 SimHub 中增加 UDP 转发目的地 **127.0.0.1:20778**，保留游戏原有的 SimHub 输入端口。游戏选择 **2025** 输出格式，发送频率建议 **60 Hz**。详见 README。

## 验证与限制

已通过源码构建、来源选择、UDP 解码、缺包与恢复、ACR 解码和共享辅助算法检查。本机 F1 25 原生接入曾观测到约 60 Hz 更新；不代表所有电脑或所有驾驶场景均已验收。

余量与踏板提示仍是响应和滑移趋势估计，不是测得的峰值摩擦或安全保证。F1 25 的 ABS / TC 开启设置不等于逐帧触发状态；缺失的活动状态不伪造。此前针对换挡增加的特殊隔离和警示渐退未包含在此版本中。
