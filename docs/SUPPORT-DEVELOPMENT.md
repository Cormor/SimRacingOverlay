# 支持开发

管理窗口侧栏的“支持开发”提供支付宝收款码与微信赞赏码，用于自愿支持软件开发。支付宝显示 `¥5.98`，微信显示 `建议 ¥6`；微信赞赏金额由付款方选择。付款使用手机完成，页面不创建订单或支付链接。

## 页面与主题

两张卡片在标题下方居中，窄窗改为单列，矮窗可滚动。支持入口有2px金色边缘轮转，减少动态时保持静止，管理窗口隐藏或挂起时暂停。

浅色主题使用黑码白底，深色主题使用白码黑底。深色主题下，“标准扫码”可将两张码恢复为黑码白底，再次点击恢复主题显示；新页面初始化时默认关闭，不保存到用户设置。

码图与标记分层：`assets/support/*-code.png` 为码面，主题反色只作用于该层；`*-marks.png` 为透明标记层，两码中心使用金色三辐方向盘，微信右下标志保持原色。方向盘的可编辑几何源为 `assets/support/wheel.svg`，PNG标记层为运行资源。码周围保留24px内边距。

## 识别说明

已有定向识别使用ZXing-C++ 3.1.1，支付宝最终浅色和深色合成图、224px码宽加24px静区的展示图，均可直接解码并与原码内容一致。该结果对应本地解码器，手机原生扫码及实际付款仍以付款端结果为准。

微信使用私有赞赏码，保留原环形结构和右下标志；深色模式的识别情况需要实际微信扫码反馈，可通过“标准扫码”恢复黑码白底。

## 打包与维护

`tools/package-app.py` 收录支持页文档与 `assets/support` 图片，运行不依赖远端图片服务；Bridge现有静态资源规则支持PNG与SVG。支持页沿用管理窗口的导航与离页处理。

更换收款码时使用新的授权原图，保留数据区、定位点和必要标志；中心装饰只在原装饰范围内处理，并重新审查受影响的识别条件。维护记录不得写入解码后的支付内容。
