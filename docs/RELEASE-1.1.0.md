# SimRacingOverlay v1.1.0

## 本次更新

- 四轮横向状态改为左右各一组双层长条：上前轮、下后轮，左右对称、同侧向中间填充。
- 主填充显示该轮当前横向滑移状态，短时趋势及有支持的轮胎力响应显示在边框颜色与辉光上，不再显示容易误解的精确余量百分比。
- 移除独立纵向条，纵向风险并入油门、刹车边框；提示连续变化，不再使用原有的 55% 滑移触发门槛。
- 纵向滑移不再直接压空横向条。轮胎卸载时，对应整条清空并显示白框辉光。
- 两组横向条默认放大 2 倍，收紧上下间距并避开方向盘上方的侧滑指示器。尺寸复位使用新的默认值，已有保存的布局保留。
- 短时物理趋势计算使用遥测生产时间，接收时间只负责数据新鲜度。

## 下载与更新

下载 **SimRacingOverlay-1.1.0-Windows-x64.zip**，完整解压后双击 **Install.cmd**。不需要另装 Electron 或 Python。

升级前正常关闭本软件和启动观察器；需要更新 SimHub 插件时也关闭 SimHub。运行新包安装器，保留已有设置、校准与布局。没有自定义布局时使用新版默认大小；已有布局可在编辑模式按需复位尺寸。

公共版继续使用通用方向盘与独立仪表，保留按钮映射、桌面 / OBS 显示及关联启动。不包含作者的个人设备配置、品牌产品照片、遥测记录或日志。

主条和辅助提示是遥测状态与趋势显示，不是实测剩余抓地力百分比。ACR / F1 25 能显示的内容取决于有效的逐轮遥测；没有对应数据的功能不伪造。

## 验证范围

当前横向条版本已获得本机驾驶使用反馈。本次发布只核对公共版变更同步、对应的最小检查、安装包清单与完整性；未重复跑驾驶测试，也未进行全新电脑或其他品牌设备的完整安装验收。
