# UI-D3设计依据与适用条件

版本：1.0 / 2026-11-03。用户要求所有设计思路、方向、细节和具体产出有理论依据，本文件将依据连到实际C/S/P定义，不把公司约定、用户偏好或规范阈值冒充理论推导。它补清当前设计的因果关系；不足处回定义或设计修正，不能用术语追认被否定的图稿。

## 依据与当前决定

| --- | --- | --- |
| B1 目标获取 | [Fitts 1954原论文](https://doi.org/10.1037/h0055392)：给定任务中，移动幅度与目标宽度共同影响运动难度。 | 小图形不应把热区也缩小；C01–14/C24–28共用足够热区、分离相邻动作。44高、48×44窗口按钮是公司/项目工程选择，不是论文推导的唯一尺寸；没有本机完成时间数据，不声称精确速度提升。 |
| B2 知觉组织 | [Wertheimer 1923原文译本](https://psychclassics.yorku.ca/Wertheimer/Forms/forms.htm)：接近、相似与结构关系影响知觉分组。 | C05/C07–09/C16/C19/C26–28、S01–05/S07/S14–15：同类操作形态一致，分组内间距较小、分组间较大；模块/画布/属性各有职责，减少混组。4px基数、16/24间距和三栏宽是共享工程取值，不把Gestalt声称为能确定唯一像素。 |
| B3 概念模型与示意 | [Norman本人对设计沟通的论述](https://jnd.org/design-as-communication/)及[signifier与反馈](https://jnd.org/opportunities-and-challenges-for-touch-and-gesture-based-systems/)：产品呈现需让用户理解操作和系统状态。 | C02–15/C17/C20–22/C24–28：折叠箭头对应展开状态，窗口动作各有清楚标记，保存状态与写入结果绑定；混合值与共同坐标不混淆，学习采用前旧值保持。S06–10/S13/S16区分焦点/选中、原值/草稿、临时显示/持久配置。默认熟悉符号仍是平台惯例选择，不靠符号本身证明用户已理解。 |
| B4 显示几何与逆变换 | 二维仿射坐标与逆映射；本项目已有 `layout.js` 的point/corners/transform及UE-UI第4节。 | C18/C22与P02–04/P10–12/P14–16/P19/P22–23：位置、缩放、旋转共享一组变换；预览缩放只改变观察尺度，指针经同一逆变换回世界坐标。现场虚影与管理器共用布局，避免分别维护位置。这是数学一致性要求，不涉及遥测模型或驾驶有效性。 |
| B5 反射与材质 | [PBRT4 Conductor BRDF](https://pbr-book.org/4ed/Reflection_Models/Conductor_BRDF)、[Roughness Using Microfacet Theory](https://pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)：导体反射由反射方向与Fresnel等决定，微表面法线分布改变反射角分布；宏观几何和环境同样参与成像。 | S17新材质研究应分别定义几何/倒角、粗糙度、环境反射和尺度，再离线合成；不是给底色印固定亮暗条。P21等距细线/统一斜带已被用户否定，理论不为它背书，materials1.0不进入实现。物理启发的屏幕材质也不等同测得的纯金反射或实物认证。 |

## 规范、平台、偏好与理论的关系

- [WCAG2.2目标大小](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)与[非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast)是约束及解释，不能代替B1/B2的机理；AA最小24及例外不等于公司默认44。
- [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/)是状态/键盘/语义实现参考；Disclosure、Slider、Select、菜单使用相应模式，支撑B3中的可理解操作。没有实际运行证据时，不称可访问性已通过。
- [Electron自定义窗口交互](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions)约束drag/no-drag与鼠标穿透；[window.open](https://www.electronjs.org/docs/latest/api/window-open)提供同源窗口关系。它们支撑实际实施能力，不是对所有窗口交互质量的理论证明。
- 黑金/白金、保留边缘辉光、核心指示与算法冻结来自用户要求；颜色/字号/圆角/阴影参数首先是公司及现有项目选择。B2/B3解释怎样分组和区分状态；具体色值并非从理论唯一推出。S11/S12沿用已有视觉资源，不改变其数据到显示的对应。

## 全部产出的映射

- P01概览：B1/B2/B3；P02–04及P08/P10–12/P14–16/P19/P22–23编辑和参考：B1/B2/B3/B4。
- P05/P17盘面、P06/P18设备、P07长选择：B1/B2/B3，保留现有业务契约与厂设资料；不新增功能阈值。
- P09控件状态：B1/B3及规范实现参考；P13/P20核心指示：B2/B3/B4及原算法/原绘制的保留条件，不将简图当新模型。
- P21只作为已否定的材料研究记录，不为它追认理论。按B5先定义、再形成M2研究与M3生成参考，最终M3c应用1.1获独立批准。公司materials2.0将暖金内部反射与原生控件几何分开：固定安全内部SVG采样、动态宽度向内裁切、普通中性/少数主操作金属面、独立hover辉光。机理约束视觉方向；生成图不是数值BRDF解，采样区、细边和模糊值是工程选择。

上述覆盖C01–28、S01–17及正式P页面。以后新增设计先确定适用机理、约束与设计变量，引用共同依据并记录差异；不能先凭视觉猜结果，再给每个像素补论文名。理论提供预测与取舍，具体参数是可解释的工程选择；真实新反馈推翻假设时修受影响定义/产物，不自动增加审批或实测轮次。
