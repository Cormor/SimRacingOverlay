# 当前运行架构

原生 Bridge 采集设备和游戏数据，发布不可变快照；每设备 / 轴保留自己的年龄，缺失和有效零值分开。浏览器通过遥测时钟请求换算年龄，并消费两路事件流。HUD 是唯一遥测计算与绘制端，管理器通过 opener 与受信任 IPC 管理 UI 和布局，不另开计算链。

计算会话从首包固定拥有者。Worker 故障后以新样本建立主线程模型；输出携输入上下文和代次，过期或不属于当前会话的结果不提交。模型处理、显示状态准备和绘制时钟分开。托盘只消费同一硬件快照，不另行枚举设备。

桌面宿主持有显示选择、管理窗、现场编辑和退出生命周期。配置与资源变化按类别发布；管理窗保存关闭后再处理需要的前端重载。直接编辑的选区、拖动、撤销和保存由管理器拥有，HUD 负责显示与转发输入。最小化暂停编辑而保留恢复快照。

Start-Overlay.ps1、Stop-Overlay.ps1 和 tools/Lifecycle.ps1 共用互斥与安装目录规范化。停止请求绑定当前桌面 PID、会话和截止时间，先保存关闭，再暂停自动拉起与结束本安装服务。桌面退出使用短 PowerShell 启动器为实际停止脚本创建独立隐藏控制台。OBS 的 Lua 消费共享布局状态；不通过修改废弃编辑配置打开编辑器。

源码、原生构建回执、运行结果分别提供各自证据。共享算法与已有研究准备保留，数据源能力和字段有效性决定可计算内容，不按游戏名称猜测能力。
