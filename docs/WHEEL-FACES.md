# 方向盘盘面

按 **Ctrl+Alt+M** 进入编辑，在“方向盘盘面”中选择外观。程序默认只内置原款；选择 **SIMAGIC GT Pro 圆盘** 后点击“下载所选盘面”，程序从本仓 GitHub Release 下载，校验完成并成功载入图片后切换。已下载盘面可离线使用。下载失败时保留当前盘面，面板提供错误信息，可再次点击下载。

切换保留方向盘模块的位置、大小、旋转和透明度。盘面选择、按键映射与仪表方式跟随布局保存，桌面与 OBS 浏览器源共用 `assets/layout.json`；下载缓存位于 `assets/wheel-packs/`。更换运行目录时，复制这两项可保留所选下载款。

## 按键与灯效

每款盘面分别定义按钮、旋钮和转速灯的位置。展开“此盘面的按键映射”，指向一行时，盘面对应位置会亮起；点击“录入”后按一下实体按键，也可直接输入按钮编号，多个编号用逗号分隔。留空清除该位置的映射，“恢复此盘面默认映射”移除此款的自定义覆盖。映射按盘面单独保存，切回原款会使用原款设置。

SIMAGIC 下载款按参考照片和[厂商公开布局](https://simagic.com/pages/details-gt-pro-hub)原创绘制，包含 8 个带灯按钮、4 个拇指旋钮、2 个七向开关、2 个 ABS / TC 旋钮与 9 段转速灯。设备驱动、连接方式和自定义配置会影响按钮编号，因此新款初始映射留空，使用上面的录入功能绑定自己的设备。

原款可继续显示已有观察器提供的灯色。下载款使用屏幕软件灯效；转速灯优先使用游戏换挡指示或换挡阈值，缺少阈值时尝试使用有效转速与最高转速的比例。9 段灯条覆盖完整的转速范围。暂停、菜单或缺少相应遥测时停止生成转速灯。这些显示功能不向实体方向盘发送灯光命令。

## 仪表显示

- **跟随盘面**：原款在盘面屏幕位置显示仪表；SIMAGIC 圆盘没有屏幕，因此不画嵌入式仪表。
- **独立显示**：仪表作为独立模块出现，可移动、缩放、旋转、调整透明度和层级。
- **隐藏仪表**：关闭仪表显示。

在模块列表显示“独立仪表”会切换到独立显示；隐藏该模块则恢复跟随盘面。撤销、重做和布局导入导出包含盘面与仪表设置。旧布局首次读取时继续使用原款及其嵌入仪表。

## 维护与验证

`wheel-profile.js` 定义数据格式、布局设置、映射与屏幕转速灯；`wheel-store.js` 负责固定清单下载及缓存。`assets/wheel-catalog.json` 记录名称、Release 资产地址和 SHA-256。新增盘面在 `wheel-packs/<id>/` 维护原创 SVG 与 `profile.json`，由 `tools/package.py` 生成独立的 `<id>.wheel.json` Release 资产。主程序包排除盘面缓存和这些可选素材，默认只有原款。

数据包仅包含 PNG 和经过校验的几何、输入映射、仪表位置数据，不执行包内代码。图片统一为 1315×1197，使用明确的轴心与校正比例。下载限制为 8 MiB、20 秒和 4 次 HTTPS 跳转，核对清单 ID 与原始字节哈希后原子保存；同一盘面的重复下载合并，失败保留已有文件。

修改时运行：

```text
node src/test_wheel_profiles.js
node src/test_wheel_store.js
node src/test_layout_editor.js
node src/test_relative_layout.js
node src/test_dashboard_cache.js
node src/test_render_clocks.js
node src/verify_algorithm_baseline.js
```

Windows Electron 场景验证使用合成输入与隔离缓存，不启动桥接或访问设备：

```text
runtime\electron\electron.exe src\test_wheel_faces_renderer.cjs <应用根目录> <profile.json绝对路径> <证据输出目录>
```

验收覆盖下载失败与重试、校验后切换、录入和映射隔离、9 段灯、无屏自动模式、独立仪表定位与显隐、撤销、OBS 页面恢复和离线缓存。状态交错还需验证迟到的布局正文、图片解码、首次清单及取消拖动，防止旧结果覆盖新选择。回归测试默认只读当前仓库；只有明确对照两仓时才设置 `OVERLAY_TEST_PAIRED=1`。
