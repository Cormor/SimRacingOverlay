# 叠加层交互与视觉规范

## 1. 需求来源与必须保持的语义

本规范定义布局编辑、驾驶视图及遥测能力的维护契约。

- 裕度在转向需求增加时连续下降，在不能继续增加转向能力时接近空条；换车、湿地及缺少几何参数时仍提供有依据的反馈。参考值更新不能引起突跳。
- 前后轴的侧偏角复用原有两个侧滑指示器：优先原生侧滑，有效原生数据保留既有范围和含义；缺少原生值时使用有输入依据的估计。不得凭空补出逐轮滑移率。
- 四条横向裕度保留旗语加入前的双倍尺寸与排列。左右两组各上前轴、下后轴。旗语位于四条上方中央，与推头／甩尾同一中线，名称和解释分两行。
- 旗语是 iRacing SDK 专属协议解释，不能用其他来源中恰好同名的数字字段触发。
- TC / ABS / ESC 表示实际触发状态；配置档位不冒充介入状态。
- F1 25 与 ACR 的算法以本晚 DeepSeek 修改前的源码及回放为对照。修编辑器不顺带改算法。
- 方向盘原始 PNG 保留，轴心与圆度校正保留。页面重写不将模型计算放回显示帧。

## 2. 信息架构

驾驶视图以透明画布呈现。所有可独立编辑的内容必须注册在 `layout.js`，包括旗语。模块包括：方向盘与仪表、两踏板及辅助边框、四轮滑移、左右裕度组、前后轴侧滑、车辆姿态状态、减速度、手刹、电子辅助、G 力球和旗语。

| 模块 | 含义与显示规则 | 无数据时 |
|---|---|---|
| 方向盘与仪表 | 设备输入、转角、档位、速度及换挡灯 | 保留轮盘，独立显示待数据状态 |
| 踏板及辅助边框 | 实际踏板输入；边框显示对应辅助提示 | 空轨道 |
| 四轮滑移 | 有符号滑移；锁死警示；悬架全伸展显示离地空框 | 空轨道，不填造数值 |
| 左右裕度 | 上前轴、下后轴；颜色与剩余能力连续变化 | 中性空框 |
| 前后轴侧滑 | 原生侧滑优先，估计角度带 F/R 与角度单位 | 破折号 |
| 推头／甩尾／侧摆 | 车辆姿态分析结果，仅事件出现时显示 | 隐藏 |
| 实际减速 | 实际纵向减速度，单位 g | 隐藏 |
| 手刹、电子辅助 | 实际输入或实际介入 | 隐藏 |
| G 力球 | 当前、轨迹、已观察峰值 | 保留基准盘 |
| iRacing 旗语 | 当前最高优先旗语及中文行动解释 | 隐藏；编辑时保留可选框 |

## 3. 编辑流程

`Ctrl+Alt+M` 进入／完成编辑；编辑期间临时显示画布，退出后恢复原来的显隐设置；完成前同步保存成功后退出。桌面和 OBS 共用同一份 `assets/layout.json`。

1. 单击模块选中；Shift / Ctrl 点击加选或取消。空白处拖框选择完整包含的模块。模块列表允许直接多选，方便隐藏、重叠及缺数据模块。
2. 拖动任意选中模块移动整个选区；方向键每次移动 1 屏幕逻辑像素，Shift 为 10。拖动过程中按住 Shift 约束为单轴，可选 8 px 网格吸附。
3. 右下角手柄以共同中心等比缩放。数值 X/Y 表示选区在当前屏幕的左上位置，不显示内部偏移量。单选允许独立宽高；多选用缩放百分比保持比例，避免旋转组件出现剪切。
4. 单选角度是绝对角；多选输入旋转增量，以选区共同中心旋转成员位置及方向。快捷按钮每次旋转 90°。
5. 每个模块独立显示／隐藏、锁定／解锁；锁定不参与位置尺寸方向操作。数据缺失仍可在编辑器看到模块边界及名称。
6. 多选支持左对齐、顶对齐、横向居中及统一层级操作。移回屏内将选区居中，找回屏外模块。
7. 移动整体直接选中全部启用模块，随后采用同一种画布拖动与数值输入，不再拖一个按钮来猜整体移动距离。
8. 复位所选恢复未锁定成员；整体复位恢复全部模块默认状态、透明度、方向、启停与层级，并按当前视区适配大小、将全体居中。两者都可撤销。展开“复位选项”可仅复位位置、尺寸、单轴大小或方向，其他属性保留。
9. 撤销／重做保留最近 80 次操作；一次拖动是一步；取消拖动恢复开始位置。Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y。
10. 导出 JSON 保存可复用布局；导入只应用模块设置，保持当前显示器与 DPI 参数。格式错误在面板提示，不改变现有布局。导入可撤销。

面板独立固定在屏幕左侧，可以拖动标题、折叠、滚动。面板不参与驾驶画布布局、不改变整体位置。窗口不随模块拖动改变原生尺寸。

## 4. 坐标契约

- 世界坐标以原始 1000×850 设计为单位，允许负值以容纳上方旗语。独立浏览器的初始舞台为 1000×1000、Y 原点 110，给旗语预留完整顶部空间；桌面沿用当前显示器的舞台参数。
- 屏幕逻辑坐标 = `stage.origin + world * stage.scale`。物理画布只由物理分辨率决定；点击从 CSS 内容区域逆变换，不以 `devicePixelRatio` 重复缩放。
- 每个模块的平移、缩放、旋转使用同一中心；绘制、命中、选框、脏区采用同一变换。绘制阶段不得隐式执行 fit/clamp 改变已存位置。
- v2→v3 迁移修正局部缩放中心，并按旗语加入前的正确横条锚点恢复。重复读入 v3 不再次迁移。既有其他模块偏移与透明度保留。
- 控件消失、禁用、旗语清除及旋转移动后，旧像素必须进入脏区清除。

## 5. 视觉系统

统一令牌位于 `ui-theme.js`（画布）和 `ui.css`（编辑器）。颜色仅有语义，不按游戏更换主题。

| 用途 | 令牌 / 数值 |
|---|---|
| 主文字 / 次文字 | `#edf5ff` / `#a4b7cc` |
| 面板 / 轨道 | `#111923` / `#1c2938` |
| 中性边界 / 选中 | `#73879d` / `#62d9ff` |
| 刹车 / 油门 | `#ff5673` / `#65e3ad` |
| 警示 / 危险 | `#ffc75a` / `#ff365d` |
| 前轴估计 / 后轴估计 | `#83d7f2` / `#f6bd84` |
| 字体 | 编辑器 Segoe UI → Microsoft YaHei UI；数值 Cascadia Mono → Consolas；中文保留雅黑回退 |
| 编辑器字体 | 主要 13 px、标题 16 px、提示 11 px；按钮不小于 32 px 高 |
| 画布字阶 | 注释 16、标签 20、主要数值 32、状态标题 40；旗语名称 28、解释 18 设计像素 |
| 旗语卡片 | 260×64；两行居中；低透明深背景、3 px 旗色边框、12 px 圆角 |
| 基础间距 | 面板 12 px、控件间 6–8 px、卡片圆角 8–12 px |
| 图标 | 撤销 ↶ / 重做 ↷、折叠 − / 展开 +；模块显示与锁定用可读文字，不依赖孤立图标 |

裕度使用连续的危险红→警告黄→余量绿，全部已填区域为同一当前状态色；不使用空间彩虹。估计、缺失与实测通过文字和单位区分。电子辅助和锁死警示保留事件特征。除原轮盘资源外，新增 UI 必须引用语义令牌，不继续扩散任意颜色、字体与字号。

## 6. 维护与验收

- `node src/test_layout_editor.js`：迁移、组变换、旋转、锁定、启停、坐标一致性、DPI 逆变换和来源隔离。
- `node src/test_flags.js`：旗语优先级及协议位。`0x2000 randomWaving` 不按黄旗解释；取消资格、维修独立解释。
- 渲染验收应覆盖完整／局部绘制的一致性、旋转、模块启停和清旗后的旧像素清除。
- 运行端最终核对版本、真实入口、已保存布局和编辑退出读回；游戏、硬件与第三方配置不在此编辑器任务中变更。
- 算法审查另记 `docs/ALGORITHM-BASELINE.md`；原始操控录制及回放属于验证资料，保留。优化后应生成有源码身份与回放结果的存档标记。

维护时记录实际执行的验证与证据；规范本身不充当测试结果。

旗语位定义参考 iRacing 原始 SDK 头文件：[irsdk_defines.h](https://github.com/meltingice/node-iracing/blob/master/lib/irsdk_defines.h)。


## 7. 当前交付版本

`ue-editor-v1` 的仪表已改为统一字体与语义色：实际档位、转速、车速、转速条；未知值用破折号，实测零保留。第一页档位反向旋转以保持读数朝上，第二页随轮盘；第二页相同仪表数据复用绘制缓存。仪表原生画布 780×248，字号为档位 128、数值 56、单位 26，再映射到轮盘的实物屏幕矩形；不把这些内部尺寸当作桌面 CSS 字号。

滑移、姿态、裕度和氛围色的完整渐变定义集中在 `ui-theme.js` 的 `palettes`。原生灯色继续忠实显示输入，照片材质与中心黄条保持原资源校正；HUD 统一采用低干扰深底、较细文字轮廓和同一字体。编辑框标签仅在选中时显示，避免全部标签覆盖驾驶组件。


## 相对屏幕的共享默认布局（1.2.0）

`layout-preset.js` 保存当前公开的控件尺寸、相对位置、方向、显隐和层级。整组水平锚点为屏幕 50%，底部留白为屏幕高度 2%，参考高度占比约 42.66%。舞台按当前显示器逻辑尺寸计算统一缩放；窄屏或小窗口先等比收进视区，再靠中下放置。DPI 只影响物理绘图分辨率。

桌面设置 `placement.mode=relative` 使用此定位方式；旧的手动绝对位置在没有该设置时继续保留。单独移动模块仍保存用户编辑值，不会每帧被重新归中。“整体复位”恢复此共享预设及中下方关系；仪表样式和预设属于可公开配置，不包含设备或账户身份。


## 可下载盘面与独立仪表（1.3.0）

编辑器“方向盘盘面”提供本地选择、GitHub下载、逐位置按键录入与仪表方式。默认只内置原款；新盘面通过校验及图片解码后才提交选择。每次选择使旧请求失效，迟到的布局正文不能覆盖新编辑。无屏盘面在跟随模式不画仪表，独立模式使用单独的dashboard模块；模式与模块显隐同步。撤销与取消拖动恢复完整布局，保留当前显示器stage。详细行为及验证入口见 [方向盘盘面](WHEEL-FACES.md)。
