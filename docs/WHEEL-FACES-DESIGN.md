# 盘面扩展设计与验收

版本：v2。用于官方实拍盘面、厂设按键与灯位接入。保留已有编辑器、用户布局、遥测算法与本地试验树；发布继续使用独立工作树。

## 用户任务与依据

用户在编辑器选择已内置或可下载的方向盘；新圆盘下载后离线可用，按真实位置显示按键和灯光反馈。无屏圆盘可使用单独仪表。盘面必须保留参考实物的外形和材质，使用速魔现成有效资源，编号有厂商依据。

- 官方实拍：[Hub + P-330R Leather](https://simagic.com/products/gt-pro-hub)，使用产品接口列出的 `HUB_P-330R_Leather_-20250207.jpg`，1920×1920。来源字节与 SHA-256 记录在 `wheel-packs/simagic-gt-pro-round/geometry.json`。
- 官方编号：SimPro Manager 1.3.2 的厂设 HID 映射及其实际图像位置，按1基编号。本仓 `factory-buttons.json` 保留映射事实、来源版本与证据位置，用户自己的重映射通过编辑器覆盖。
- 官方灯数：GT Pro Hub 产品说明与软件 `speed1` 至 `speed9` 均为9灯；不按生成图或未点亮照片猜数。

## 需求—设计—验收

| ID | 结果与设计取舍 | 验收判据 |
| --- | --- | --- |
| W01 | 默认仅内置原款，新款为GitHub独立数据资产 | 主ZIP无新盘素材/缓存；编辑器下载、校验、解码后才提交；断网重启可用 |
| W02 | 官方实拍作材质，去背景及统一尺寸，保留真实结构 | 横向S、3螺钉、8灰按键、2下方黑七向、4红旋钮、实际后拨片；与官方源逐项对照，不添加隐藏的K版控件 |
| W03 | 外缘为正圆，轴心与绘制/按键/灯位共用同一变换 | 正圆半径562、轴心655/602.5、校正1/1；0/90/180/270°外缘与轴心一致；保留皮纹及内沿物理形状 |
| W04 | 左右缝线完整，红色回正标不跨线 | 同尺度对比官方源、透明图；左右上弧均保留真实红线，红标区域干净；浅色和棋盘背景无漏切/残底 |
| W05 | 按厂设定义预置按键，可按盘面覆盖 | 8键默认7/8、3/4、6/5、1/2；红旋钮、黑七向和拨片对照factory表逐路高亮；旧盘编号不渗入 |
| W06 | 9灯的形状和位置对应实物，ABS/TC灯与旋钮分开定位 | 9个独立灯点落在真实窄灯条；贴纸灯只作用于相应区域；红旋钮外形不被虚构灯圈覆盖；遥测失效停止RPM灯 |
| W07 | 无屏圆盘不画嵌入仪表；支持独立仪表 | auto无屏、separate独立拖动/缩放/显隐，hidden关闭；独立挡位不随方向盘反转 |
| W08 | 选择、保存、撤销和异步结果一致 | 失败保留旧盘；迟到正文/解码/清单不覆盖新意图；操作中不静默退出；拖动取消/Undo不回退整套布局 |
| W09 | 本地调试代码与暂存保留 | 两原仓HEAD、完整状态与27份stash OID前后相同；不替换Apps入口 |

## 页面与状态

可编辑设计源：`design/wheel-faces-v2/prototype.html`；视口1440×1000，CSS px。导出图用对应状态ID命名。既有字号、边距与语义色沿用 `ui.css` / `ui-theme.js`，不全量换肤。

| 状态ID | 页面与组件 | 视觉及操作约定 |
| --- | --- | --- |
| D01 | 编辑器关闭选择器／新款待下载 | 当前原盘保留；列表明确新款可下载，下载按钮提供入口 |
| D02 | 新款已选择／盘面与9灯 | 正圆实拍、干净红标、完整左右红缝；状态显示已选择，无内嵌仪表 |
| D03 | 此盘面按键映射展开 | 使用厂设编号；提示可覆盖用户改映射；指向行或按下实体键高亮对应位置 |
| D03b | 映射滚动延续 | 七向完整逗号集合、4红旋钮和2拨片可完整阅读 |
| D04 | 独立仪表 | 浮动仪表与盘面分开，不随盘面转动，模块可独立选中与保存 |
| D06 | 选择器展开 | 当前原款与可下载/已下载款分别标明，当前选择、键盘活动项与取消操作清楚 |
| D05 | 下载失败 | 当前原盘保留，错误与重试就近显示，操作结果不冒充已选择 |

选择器使用原生select：关闭输入框与展开列表分别查看，只有两款时保持短列表；键盘选择、取消以及焦点可见沿用原生行为。此次不新增选择器框架或动效。方向盘连续转动沿用现有显示插值；改动只替换材质/数据，不改变遥测求解时钟。
