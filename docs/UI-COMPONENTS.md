# RacingOverlay UI 组件与样式定义

定义版本：UI-D3 / 2026-11-04浅色与托盘增量，初版2026-11-03。先于本版页面设计建立；本文件是页面、状态图与程序员实现的输入。适用Windows桌面管理窗、设备页及桌面现场参考；不改变遥测算法、数据含义或既有盘面结构。

## 依据、单位与复用

- 公司 `SoftwareCompany/design/README.md` 的“所有控件与样式先定义”及 `tokens.json` v2。共享定义直接复用，以下明确本项目映射与差异。
- 通用形态与交互引用公司 `design/components.md/css` v1.1。本项目C01–28为公共组件的实例映射和业务扩展，通用缺口回到共享库补齐，不把Racing专属名称或算法塞进公共库。其他项目按需复用。理论及适用条件见 [UI-BASIS.md](UI-BASIS.md)。共享材质v1.0撤回；现行材质为公司materials2.3连续柔光边环，浅色采用tokens2.1.0清亮白金。
- 几何统一为CSS px／屏幕DIP；DPI只影响物理画布。布局坐标、旋转与缩放继续使用本仓 `layout.js` v3，不因管理窗改变模型。
- 交互控件通用热区44px；窗口控制另选48×44px，属于本项目自绘桌面标题栏选择，不宣称Windows强制此数值。全部标题栏按钮明确 `no-drag`。
- 图标统一线性SVG，20px画框、1.5px描边；窗口控制16px图形。不能用“— □ ×”文字串代替按钮设计。
- 深色／浅色直接引用公司语义值，正文16px、说明14px、短标签12px；等宽数字使用Cascadia Mono／Consolas。HUD沿用 `ui-theme.js`，不换成管理端金色。

## 通用状态及组合

默认使用surface；悬停surfaceRaised；按下使用hover的更深／更浅派生层；焦点3px focus实线、3px外偏移；禁用有原因为文本或说明，不只降透明度。选中使用accent细边与轻底色，焦点只表达键盘位置，不再加一层选中填色。错误用danger＋文字，加载用状态文案与必要禁用；成功以持久状态文字表达。纯装饰无点击和键盘行为。

优先级：禁用阻止动作；错误反馈就近持续；选中与焦点可同时存在但各自只一层。长文本可换行或局部省略并提供完整名称，不能挤掉主要动作。输入框文字字号继承16px。连续拖动即时跟随，不加缓动或弹簧；本轮导航和展开切换也即时完成，不增加装饰动画。

## 样式定义目录

S01语义颜色、S02字体/数字、S03间距与网格、S04圆角、S05边界、S06焦点、S07选中、S08禁用、S09错误、S10窗口控制危险悬停、S11层级/阴影、S12辉光、S13透明度、S14滚动、S15响应、S16即时切换。

S01–S05及S11采用公司令牌：canvas/surface/surfaceRaised/text/textMuted/border/accent/focus/danger/success/warning/info；4px基数，卡片阴影仅管理窗面板0/8/24与黑色20%（浅色12%），弹出层高于属性和导航，选框低于弹层。S06–S10按上表通用状态；S12复用现有HUD辉光，不将整张盘面发光；S13按C11/C22分别处理持久与会话值。S14保留原生滚动可见性；S15默认1440×960，最小960×640，小于1200属性单栏抽屉、可收起模块；小于1000默认双栏收起，导航缩图标保留Tooltip；设置内容单列可滚，不裁断主要操作。S16所有本次新切换即时，不创建运动solver，尊重减少动态。

S17静态材质：采用公司materials2.3连续柔光精抛边环，唯一维护源为`SoftwareCompany/design/algorithms/gold-ring/`。主操作内面使用主题语义填金，物理金属仅2CSSpx边环；普通默认中性、hover按显式类显示环，辉光独立，选中/禁用/焦点沿2.3定义。运行仅本地`assets/materials/gold-ring-static@2x.png`（9420B），8px九宫格角区保持R8/2px可见环，直边伸缩属于静态照明近似。正式状态见[S02](../design/light-palette-v1/S02.md)，原S01/M3c/研究保留历史；旧M3c位图包装不再进入运行。浅色引用公司tokens2.1.0；控件几何、热区、文字和核心HUD色义/算法沿原定义。

S18托盘方向盘：复用公司 `design/icons/steering-wheel/` 1.0 几何及 16DIP 多分辨率双态 PNG。灰白为未确认/未连接/状态失联，金色要求当前有效采样的明确转向绑定设备、Driving 设备或已确认 R25 Ultra 产品身份。设备元数据和采样来自 Bridge 同一份快照，不额外枚举。HUD 主 frame 每秒上报按每设备采集年龄筛选的摘要，不传轴值/按钮/配置令牌；重复或旧采集序号不能延长寿命。采集有效期与3秒HUD通信期限分开，导航/renderer退出使报告失效，实际退出清理计时器与Tray。原图标、菜单和tooltip样式保持，细节见 `design/tray/README.md`。

每个表面、边框、文字、图标、阴影和状态都由以上ID定义；新实例引用这些定义，不在页面或实现里临时猜样式。若出现目录未覆盖的控件或状态，先补本文件再设计／改代码。

| C33 本段G峰值与退出 | 概览、G球属性和托盘提供“重置本段G峰值”，含义为清除统计后继续记录，不中断当前G测量。换车/确认新会话开始新段；明确暂停/菜单保留本段且不采峰，真实断流沿用30秒过期规则；不凭每圈或一次包倒序猜新段。托盘退出复用保存关闭及暂停自动启动协议，失败可重试。 |

更多操作仅保留低频布局文件/整体复位等命令；全选在列表、吸附在画布、所选复位在属性，按动作对象定位。按钮与状态始终保留可发现反馈，长页和缩放适配以可达全部内容为条件。


C29窗口补充：管理窗是独立任务栏窗；最小化不留下置顶iconic标题条，不变成托盘隐藏。恢复应继续同一编辑状态、位置和尺寸；原生暂停不改变布局页意图。HUD聚焦时一次上移可见且未最小化的面板，不揭开全屏/拖动时暂藏面板。
